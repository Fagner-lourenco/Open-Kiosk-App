│ PROBLEMAS COMUNS                                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  ❓ LED não pisca nenhuma vez após ligar?                                   │
│     → Desconecte USB, aguarde 5s, reconecte                                 │
│     → Verifique conexão do LED no GPIO 19                                   │
│     → Pressione botão RESET do ESP32                                        │
│                                                                              │
│  ❓ LED fica sempre aceso, não pisca?                                       │
│     → GPIO 19 travado em HIGH (problema no código)                          │
│     → Reinicie o ESP32 (botão RESET)                                        │
│     → Remova e recoloque o LED                                              │
│                                                                              │
│  ❓ LED pisca estranho, padrão diferente?                                   │
│     → Pode ser código antigo no ESP32                                       │
│     → Faça upload novamente do firmware                                     │
│     → Verifique Serial Monitor (115200 baud) para erro real                 │
│                                                                              │
│  ❓ Válvula não abre mesmo com teste?                                       │
│     → LED pisca? Sim = Código OK, verificar circuito                        │
│     → LED pisca? Não = Problema com GPIO 19                                 │
│     → Fonte 12V conectada ao relé?                                          │
│     → Relé recebendo sinal do GPIO 5?                                       │
