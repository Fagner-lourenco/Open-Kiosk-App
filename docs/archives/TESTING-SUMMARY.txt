    $ bun test:ui

     ├─ Setup: offline mode ativado
     ├─ Ação: compra com Point, estoque decrementado
     ├─ Evento: reconectar internet
     └─ Resultado: ✓ Transação sincronizada, sem duplicata

  3️⃣ ERRO DE PAGAMENTO: PIX expirado + retry
     ├─ Setup: PIX gerado
     ├─ Evento: 5 minutos passam sem confirmação
     ├─ Ação: usuário gera novo QR
     └─ Resultado: ✓ Novo PIX válido, sem cobrança duplicada

  4️⃣ FALHA DE DISPENSA: Hardware indisponível
     ├─ Setup: pagamento confirmado
     ├─ Evento: ESP32 desconectado
     ├─ Ação: retry automático 2x
     └─ Resultado: ✓ Refund OU aviso ao operador

  5️⃣ CONFLITO DE ESTOQUE: Overstock offline
     ├─ Setup: offline, estoque local = 10
     ├─ Evento: 2 clientes vendem 8 cada (total 16)
     ├─ Reconexão: servidor só tinha 10
     └─ Resultado: ✓ Refund automático ou reversal
