##  BUGS CONFIRMADOS: 4

### BUG #1 [CRÍTICO]  JSON Parser sem escape strings
- Arquivo: src/services/esp32CommunicationService.ts
- Função: extractCompleteJsons()
- Impacto: Perda de mensagens, timeouts BLE/USB
- Prova: Contador de { } sem state machine de string

### BUG #2 [MODERADO]  Parsing duplo de JSON
- Arquivo: firmware/firmware.ino
- Função: processCommandAndGetResult()
- Impacto: Latência em clientes malformados
- Status: Ineficiência defensiva

### BUG #3 [MODERADO]  Import dinâmico USB frágil
- Arquivo: src/services/esp32CommunicationService.ts
- Função: loadUsbSerialPlugin()
- Impacto: Falha silenciosa em Android
- Prova: Sem fallback module.default

### BUG #4 [MODERADO]  Falta validação input em Cloud Functions
- Arquivos: functions/src/auth/*.ts, functions/src/billing/*.ts
- Funções: setAdminClaims(), createCheckoutSession()
- Impacto: Injection de claims, violation de schema
- Prova: Usar TypeScript sem Zod/Joi validation
